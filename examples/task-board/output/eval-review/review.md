# UX-ревью — «Доска задач»

Сопоставил [исходный HTML](../../../../evals/task-board/input/review-fixture.html) с [брифом](../../../../evals/task-board/input/brief.md). Прототип позволяет создать задачу с названием и увидеть её в списке. Назначение ответственного и завершение задачи отсутствуют, поэтому основной сценарий из брифа пока нельзя пройти целиком.

## Что проверено

Прочитал HTML и обработчик формы. В Chrome без графического интерфейса отправил форму с названием из пробелов, затем исправил ввод и отправил её повторно. На ширинах 1280 и 320 CSS-пикселей пустой ввод показал ошибку и не добавил задачу. После исправления задача появилась в списке, ошибка скрылась, поле очистилось. Горизонтального переполнения в этих тестовых состояниях не было.

Форма отправлялась программно через браузер. Ручное управление с клавиатуры, озвучивание экранным диктором и работа на физическом телефоне остаются непроверенными. Проверка на участниках команды не проводилась.

## Следующая проверка

Сначала довести сценарий назначения и завершения до рабочего состояния и добавить подпись и связь с ошибкой. Затем пройти сценарий с клавиатуры и экранным диктором, включая исправление ошибки. Для проверки концепции дать участникам команды задачу создать поручение для коллеги, найти его на доске и завершить. На телефоне отдельно проверить, видны ли ответственный и статус.
