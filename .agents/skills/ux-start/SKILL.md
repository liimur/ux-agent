---
name: ux-start
description: Start or update a UX project brief from a task and available evidence; use when defining users, goals, scope, and research gaps.
---

Read `AGENTS.md` and `docs/host-agent.md` in the repository root. Inspect the supplied task and sources, and create or update the project's brief using `templates/PROJECT.md` where useful. Separate source facts, assumptions and unresolved questions; identify people, jobs, platform, desired outcomes, scope, constraints, language and available evidence. Proceed with explicit assumptions when reasonable; ask only if a necessary decision is blocked. Do not invent user research. Save to the requested destination and report it, along with material gaps and any checks performed.
