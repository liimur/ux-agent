# Information architecture

Apply these rules to navigation, search, labels, and content models. Use [research and measurement](research.md) when turning a proposal into a test.

- **IA-1 — Name the decision before drawing the map.** Record whose task is difficult, which content or paths cause confusion, and what improvement the team expects. Give each map a purpose and scope. Identify whether it depicts the current structure, a proposed one, or a comparison. Abby Covert, *How to Make Sense of Any Mess* (2014), chs. 1–2 and 3, discussion of diagram scope and purpose.
- **IA-2 — Keep a preferred label and record the words people actually use.** For concepts that affect navigation or search, capture the intended meaning, preferred label by locale or context, aliases, and likely ambiguities. Use consistent labels for the same action in the same context. Consider mapping legitimate aliases in search or migration, and check that they lead to the intended result. Covert, ch. 4, controlled vocabulary. Search mapping is an application of the source.
- **IA-3 — Match classification to the kind of distinction.** Use clear membership rules for stable attributes. For overlapping topics, compare a hierarchy with tags or multiple entry paths using representative and borderline items. Document how to classify those items and test whether people can find them. Preserve one authoritative record where several paths lead to the same item. Covert, ch. 6, discussion of exact and ambiguous classification and combining taxonomies. The authoritative record is an implementation suggestion.
- **IA-4 — Evaluate the structure against the original goal.** Choose an indicator such as successful first choices or finding the right document without help. Record a baseline when available. Compare the navigation map, task paths, and vocabulary to catch mismatches. Revisit decisions when evidence or content changes. Covert, chs. 5 and 7. A tree test or task walkthrough can help answer a specific findability question. Label the evidence actually collected.
