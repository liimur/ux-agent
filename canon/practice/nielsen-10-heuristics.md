# Usability review prompts

Use these prompts to investigate risks in a specific task. Reference the heuristic number and describe what happened, who is affected and how to test the proposed change.

| Where to look | Prompts and Nielsen references |
| --- | --- |
| Starting the task | **H2** Compare interface terms with how people describe the task. **H4** Look for the same action under different names across screens. **H8** Check whether nearby promotions or secondary actions interrupt the task. |
| Choosing a next step | **H6** Look for information people must carry from a previous screen to make the current choice. **H7** Try the task as a first-time and a frequent user. Check whether shortcuts help frequent users while the ordinary path remains discoverable. |
| Submitting or changing something | **H1** Try saving over a slow connection and look for confirmation of the outcome. **H5** Check whether a likely mistake is detectable before it has consequences. **H3** Try backing out of a change and check what happens to work already entered. |
| Recovering with help | **H9** Trigger a recoverable error and follow the instructions on screen. **H10** Try locating task-specific help from the point where you got stuck and following it without prior product knowledge. |

Source: Jakob Nielsen, [*10 Usability Heuristics for User Interface Design*](https://www.nngroup.com/articles/ten-usability-heuristics/).
