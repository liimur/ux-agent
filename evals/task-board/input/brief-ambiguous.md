# Бриф: Отчёты на доске задач

Синтетические данные для проверки.

Нужен раздел отчётов на доске задач. Руководитель отдела хочет видеть, сколько задач закрывает каждый участник за неделю, и сравнивать участников между собой. Участники команды на встрече сказали, что им нужен список своих просроченных задач, а сравнение друг с другом их беспокоит. Кто из них главный пользователь раздела и показывать ли сравнение участников, пока не договорились. Срок — следующий спринт. Русский язык интерфейса.
