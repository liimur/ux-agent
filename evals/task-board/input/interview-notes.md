# Заметки интервью с дизайнером доски задач

Синтетические данные для проверки. Сессия 1, разбор кейсов. Дословные фрагменты в кавычках.

**Кейс «Старая доска».** Раньше команда пользовалась доской, где перед закрытием задачи всплывало окно «Вы уверены?». Дизайнер: «Все жали "Да" не глядя, окно только раздражало. Закрытие задачи легко откатить, так что лучше дать кнопку "Отменить" в сообщении». На вопрос, где окно подтверждения всё же нужно: «Удаление задачи — там да, оно не откатывается».

**Кейс «Карточка задачи».** Первая версия показывала только аватар ответственного. «У нас Анна Миронова и Алексей Морозов, оба "АМ", путали постоянно. Имя должно быть текстом». Позже: «Аватар можно, если места хватает, но не вместо имени».

**Про цвета статусов.** «Я бы делал выполненные задачи просто бледнее, серым текстом, без значков — так чище». Интервьюер уточнил контраст, дизайнер ответил: «Ну, светло-серый, как в Linear».

**Про сроки.** «Просроченное всегда наверх. Хотя в первой версии сроков, кажется, нет — тогда неважно».

**Границы делегирования.** «Набросать экран агент может. Но что показывать руководителю про людей — это не дизайнерское решение, это я бы с продактом согласовывал».
