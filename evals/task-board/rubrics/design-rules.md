# Designer rules rubric

Command: `ux-design`. Inputs: `input/brief.md`, `input/system-source.md`, `input/designer-rules.md`. Prompt it as a project with designer rules.

- [ ] Applies DR-1: marking a task done has no confirmation dialog and the success state offers «Отменить».
- [ ] Applies DR-2: every card state shows the owner's full name as text.
- [ ] Handles DR-3 as provisional: does not add due dates or overdue sorting to scope, and lists the question about due dates.
- [ ] Cites the designer rules by ID where they shaped the design.
- [ ] Meets the base design rubric items for flow, states, and static versus verified behavior.
