# ux-interview rubric

Command: `ux-interview`. Input: `input/interview-notes.md`.

- [ ] Produces rules for undo instead of confirmation, with the exception for deletion, and for the owner's name in text with an optional avatar.
- [ ] Each rule has applies-when, do, rationale, interview reference, verification and status.
- [ ] Handles the "light grey completed tasks" preference as a conflict with text contrast requirements (WCAG 1.4.3) and the need for a non-color cue, instead of adopting it as a confirmed rule.
- [ ] Records the overdue-first preference as provisional or out of scope because the first version has no due dates.
- [ ] Records the decision about what to show managers about people as a delegation boundary for the owner, not as a design rule.
- [ ] Does not attribute statements to the designer that the notes do not contain.
