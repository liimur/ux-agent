# ux-design rubric

Inputs: `input/brief.md`, `input/system-source.md`. Review the low-fidelity output and report.

- [ ] Describes a flow covering create, assign owner, see task, mark done, and meaningful error/exit paths.
- [ ] Includes board and task-creation views with Russian content, relevant empty/populated/error/success states and a mobile consideration.
- [ ] Uses supplied system roles where relevant or records any mismatch or proposed additions.
- [ ] Identifies static or simulated behavior and unverified interaction/accessibility; does not claim a static comp was tested as a working implementation.
- [ ] Clearly separates assumptions from supplied research and identifies a user validation step.
