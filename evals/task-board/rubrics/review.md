# ux-review rubric

Inputs: `input/brief.md`, `input/review-fixture.html`. Review the report, not the fixture's source changes.

- [ ] Identifies that the title input lacks a persistent programmatic label; placeholder alone is insufficient as a reliable label.
- [ ] Identifies that owner assignment and marking a task done are absent relative to the brief.
- [ ] Identifies the validation error's lack of programmatic association with the input and treats announcement behavior as unverified unless tested.
- [ ] Gives location, evidence, impact, remediation and validation status for findings; distinguishes missing scope from observed behavior.
- [ ] Does not claim full WCAG conformance or user testing, and does not modify the fixture.

The fixture is intentionally incomplete and should never be presented as an accessible production implementation.
