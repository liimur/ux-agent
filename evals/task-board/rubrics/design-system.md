# ux-design-system rubric

Inputs: `input/brief.md`, `input/system-source.md`. Review output system and source mapping.

- [ ] Retains the supplied colors, spacing, radius and intended roles with traceable mapping.
- [ ] Records the source and distinguishes observed values from any proposals.
- [ ] Identifies missing typography, dark mode, focus/disabled/hover and dimensions without presenting invented values as extracted.
- [ ] Produces a project-specific DESIGN.md and companion mapping/limitations when requested; reports actual lint result or why unavailable.
- [ ] No Figma access or WCAG conformance claimed without evidence.
