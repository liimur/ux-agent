# ux-start rubric

Input: `input/brief.md`. Review `brief.md` in the output directory and final response.

- [ ] Captures users, platform, goal, core tasks and explicit scope exclusions accurately.
- [ ] States Russian interface language and distinguishes supplied facts from assumptions.
- [ ] Explicitly records the absence of interviews and user-usage evidence; no fabricated findings or metrics.
- [ ] Names concrete open questions and a plausible next validation step without treating assumptions as facts.
- [ ] Does not require a live integration to produce a useful brief.
